Wald Compatibility Curve

Reconstruct which candidate effect sizes are more or less compatible with an observed estimate and reported 95% confidence interval under a one-parameter Wald approximation.

This educational research tool does not calculate an exact profile likelihood, validate a clinical threshold, or provide clinical decision support.

      Exports

      When the local runtime is ready, update the curve to populate the plot, reconstructed summary, threshold lookup, caption, and exports.

      Higher curve values indicate greater compatibility with the observed estimate under the reconstructed Wald model. They are not posterior probabilities that a candidate effect is true.

      Interpretation and scope

      The curve is the two-sided Wald p-value function across candidate effect sizes. This app accepts only reported 95% intervals and does not produce binary “significant/not significant” labels.
